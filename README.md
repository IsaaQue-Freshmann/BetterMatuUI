# BetterMatuUI

码图（[matu.uestc.edu.cn](http://matu.uestc.edu.cn)）的**桌面客户端**：把uestc C 语言作业平台
套一层简洁现代的原生界面，并把题库、提交、评测结果和统计数据搬到本地。

用 Python + PySide6 写成，界面是**全矢量**——图标是内嵌 SVG 路径，形状、圆角、
渐变；亮/暗主题可切换。

> 本项目是个人学习用途的第三方客户端，**只服务使用者自己的账号**：
> 不做批量刷题、不做自动重试、不绕过平台的任何评测逻辑。

---

## 功能

**我的班级** — 左侧目录树按「班级 → 作业 → 题目」组织，层级与站点一致；
右侧是题面 + 语法高亮的编辑器 + 提交按钮 + 评测结果。

**题目中心** — 层级与站点相同（搜索作业 / 作业状态 / 提交总结 / 题目总表）。
「题目总表」就是完整题库，每道题都能直接编写、提交、看结果。

**本地文件与回溯** — 每道题下面是一份「文件列表」，混排两类内容：

|      | 来源                        | 能做什么                       |
| ---- | ------------------------- | -------------------------- |
| 本地文件 | 进入题目时自动新建，以时间命名，分数显示「未提交」 | 编辑、提交；切换时自动存档              |
| 历史提交 | 站点上已评过分的记录                | 只读查看扣分原因，一键**回溯**取回当初提交的源码 |

回溯取回的代码是**只读**的，点「重新编辑至新文件」会把它复制成一个新的本地文件再继续改。

**数据中心** — 个人信息 + GitHub 式提交热力图（一天一格，共 53 格）+
三角雷达能力图 + S/A/B/C/D 综合评级 + 提交次数趋势折线图 + 提交明细。

三项指标都归一到 0-100：

- **正确率** = 拿过满分的题目数 /（这些题里未拿满分的提交次数 + 拿过满分的题目数）。
  分子按**题目数**算，所以反复刷同一道题不会提高它。
- **考勤度** = 日均提交次数映射到 0-100（对数，20 次/天 = 100）。
  分母里「有提交的那天算 1，没提交的那天算 0.2」，从账号 ID 前四位那年的 9 月 1 日起算。
- **狗卷度** = 拿过满分的题目数 ÷ 题库总题数。

**系统帮助** — 学生手册与提交注意事项内置在项目里（站点静态内容，对所有账号一致）。

**设置** — 账号与登录、外观主题（亮/暗/跟随系统、字体字号）、请求策略、数据与缓存。

## 环境要求

- Python 3.9+（在 3.9.6 / macOS 上开发）
- PySide6（官方提供 `cp39-abi3` 稳定 ABI 轮子，Python 3.9 也能装最新版，不必升级解释器）

## 安装与运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

./run.sh          # 等价于 PYTHONPATH=src .venv/bin/python -m matu.ui.app
```

首次打开是空状态，去「个人中心」登录后会自动开始加载数据。

## 项目结构

```
src/matu/                 应用源码（唯一一份，跨平台共用）
  core/                   与界面无关的核心层，可独立测试
    client.py             登录、会话、串行限速、只读闸门
    parsers.py            HTML 解析（站点改版只需要改这里）
    refresh.py            数据加载流程（班级 / 提交记录 / 题库）
    submit.py             提交与取回源码（回溯）
    accounts.py           按账号隔离的存储
    store.py              SQLite 读写
    stats.py              数据中心的三项指标
  ui/                     PySide6 界面
    theme.py              设计令牌（颜色 / 圆角 / 间距 / 字体）
    icons.py              29 个内嵌 SVG 图标
    charts.py             热力条、三角雷达、折线图（全部自绘）
    widgets.py            自绘控件（按钮 / 卡片 / 徽章 / 面包屑 / 步进器）
    sidebar.py            左侧菜单栏（可折叠成图标模式）
    pages/                各个页面
  resources/              内置资源（帮助文档、应用图标）
tools/                    开发期脚本，不进打包产物
mac/  win/                打包配置与图标
docs/                     接口文档与设计文档
```

## 工作原理

**数据全部来自站点，没有第三方接口。** 登录、题目、作业、提交记录、评测结果、
以及回溯用的源码，都是从 `matu.uestc.edu.cn` 的页面解析出来的。

**数据按账号隔离存放**（在项目之外）：

```
~/.bettermatu/accounts/<账号>/
    matu.db            SQLite：题目、班级、作业、提交记录、本地文件
    session.json       该账号的会话
    snapshot.json      导出快照
```

换账号不用重新配置，但要重新加载数据——因为**内容随账号不同**
（有哪些班级、哪些作业、哪些题目，都是账号私有的）。

**缓存只用于离线查看**：登录状态下是「点什么加载什么」——
打开某道题就刷新那道题的提交记录，点回溯就重新取那份源码，
取到什么就用什么覆盖本地；未登录时才读缓存。

**请求克制**：所有请求串行、保持最小间隔（默认 300 毫秒），单次运行有请求上限，
不做并发、不做轮询、提交失败不自动重试，且有代码层面的只读闸门兜底。

## 打包

```bash
.venv/bin/pip install pyinstaller
.venv/bin/pyinstaller --windowed --icon=mac/BetterMatuUI.icns \
    --name BetterMatuUI \
    --add-data "src/matu/resources:matu/resources" \
    --paths src src/matu/ui/app.py
```

`--add-data` 不能省：内置的帮助文档和应用图标要一起进包，
否则打包后「系统帮助」是空的、图标也会丢。

图标由 `tools/build_icon.py` 从**界面侧栏那个 logo 的同一个矢量绘制函数**生成，
所以界面上的标记、窗口图标、打包后的应用图标永远一致。

## 开发工具

```bash
.venv/bin/python tools/selftest.py            # 离线解析自检（不联网）
.venv/bin/python tools/probe.py               # 只读结构探针
.venv/bin/python tools/crawl.py               # 命令行数据加载
.venv/bin/python tools/screenshot_ui.py       # 离屏渲染界面截图
.venv/bin/python tools/build_help_docs.py     # 重新生成内置帮助文档
.venv/bin/python tools/build_icon.py          # 重新生成图标
.venv/bin/python tools/reset_state.py         # 恢复首次打开状态（会先备份）
```

凭据通过环境变量 `MATU_USER` / `MATU_PASS` 注入，来源由使用者的 shell 掌握，
**项目内不记录任何账号信息**。
